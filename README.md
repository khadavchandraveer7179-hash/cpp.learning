In this game, the computer has a secret number, and the player tries to guess it.
The program uses if-else conditions to check whether the guessed number is:
✅ Correct
📈 Too high
📉 Too low
🛠️ Concepts Used
C++
if-else statements
cin and cout
Variables
Basic input/output
▶️ How to Run
Compile and run the C++ program:
g++ guess_number.cpp -o guess_number
./guess_number
💻 Example
Guess the number: 7

Too low! Try again.
